# bats-agriguard-website

Hệ thống Website & Dashboard Quản lý Truy xuất Nguồn gốc Nông sản BATS-AgriGuard (Plantation Code Integrity & Traceability System).

## Công nghệ sử dụng
- **Framework:** Next.js 15 (App Router)
- **UI Library:** React 19, Lucide React
- **Bản đồ không gian:** Leaflet, OpenStreetMap
- **Styling:** Vanilla CSS, Design System BATS-AgriGuard (Dark Forest Green `#0A3827`, `#0D4E35`, `#F6F6F0`)

## Cài đặt và Khởi chạy

```bash
# Cài đặt dependencies
npm install

# Khởi chạy máy chủ phát triển
npm run dev

# Mở trình duyệt tại
http://localhost:3000
```
